# Escritoire

**Write it, draw it, link it.**
写得下，画得出，连得上。

个人创作平台。以文章为主体，手绘板（excalidraw）与架构图（drawio）作为附图被文章引用和链接。

## 状态

命名已定稿，见 [NAMING.md](./NAMING.md)。平台形态尚未开始搭建。

## 开源与部署

- **代码开源**：MIT，见 [LICENSE](./LICENSE)。
- **私有部署**：成品只跑在自己的私有网络里，不对公网开放。

### 部署前提

- **局域网优先**：一台常开的小主机，局域网内访问，数据与静态资源都在本地。
- **不依赖云服务**：不引入必须联网才能工作的外部 SaaS；图床、存储、认证全部落在本地。
- **结构上兼容组网**：日后要在外面用，加一层 Tailscale（或同类）即可，不需要改架构。
- **公开域名不是前提**：内网按主机名/IP 访问；只有当某部分真的要对外开放时，才需要 `escritoire.dev`。
